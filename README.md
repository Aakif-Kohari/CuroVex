# CuroVex

> Explainable AI framework for drug repurposing using biomedical knowledge graphs and counterfactual reasoning.

**Status:** 🚧 In active development — BE Final Year Project, 2026–2027

## What is CuroVex?
CuroVex identifies potential new therapeutic uses for existing drugs by combining biomedical 
knowledge graphs with graph-based machine learning. Unlike existing systems, it explains 
predictions using counterfactual reasoning — testing whether removing a piece of evidence 
actually changes the outcome.
